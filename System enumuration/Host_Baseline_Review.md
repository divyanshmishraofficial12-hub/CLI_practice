# Host Baseline Review - CTF Write-up

This write-up covers the walkthrough and solution for the **Host Baseline Review** challenge under the **foundation / sysinfo** category on [CLI-Games](https://www.cli-games.com/terminal).

---

## 🎯 Challenge Objective

The Atlas application host at `10.0.3.10` (`atlas-app-03`) has been assigned for a read-only baseline review. Confirm the host and operating-system identity, establish your account context, then correlate the active application process with its listening socket.

---

## 🖥️ Target Details

* **Target IP:** `10.0.3.10`
* **Hostname:** `atlas-app-03`
* **SSH Credentials:** `observer` / `Baseline!Map2`
* **Category:** Foundation / Sysinfo
