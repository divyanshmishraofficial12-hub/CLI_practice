# First Scan - CTF Reconnaissance Lab

This repository documents the solution and write-up for the **First Scan** challenge under the Reconnaissance category on [CLI-Games](https://www.cli-games.com/terminal).

---

## 🎯 Challenge Objective

An internal server at `10.0.0.2` (`srv-internal-01`) is scheduled for an exposure review. The task is to scan the target using `nmap`, identify listening TCP services, locate the web service, and extract the database product and version.

---

## 🖥️ Target Information

* **Target IP:** `10.0.0.2`
* **Hostname:** `srv-internal-01`
* **Category:** Foundation / Recon
