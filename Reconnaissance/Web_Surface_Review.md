# Web Surface Review - CTF Reconnaissance Lab

This write-up covers the walkthrough and solution for the **Web Surface Review** challenge under the Reconnaissance category on [CLI-Games](https://www.cli-games.com/terminal).

---

## 🎯 Challenge Objective

Inventory the public HTTP service on `10.0.0.8`, inspect the public page source, and follow disclosed configuration references to retrieve application versioning and exposed secrets.

---

## 🖥️ Target Information

* **Target IP:** `10.0.0.8`
* **Hostname:** `app-prod-02`
* **Category:** Foundation / Recon
