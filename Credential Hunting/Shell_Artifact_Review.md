# Shell Artifact Review - CTF Write-up

This write-up covers the walkthrough and solution for the **Shell Artifact Review** challenge under the **foundation / creds** category on [CLI-Games](https://www.cli-games.com/terminal).

---

## 🎯 Challenge Objective

A developer workstation at `10.0.2.10` (`dev-ws-04`) was flagged after credentials appeared in command-line activity. Review the user's shell history, identify the database and cloud credentials recorded there, and follow the request trail into the application log.

---

## 🖥️ Target Details

* **Target IP:** `10.0.2.10`
* **Hostname:** `dev-ws-04`
* **SSH Credentials:** `dev` / `developer1`
* **Category:** Foundation / Creds
