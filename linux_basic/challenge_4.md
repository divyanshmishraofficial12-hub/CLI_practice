# Transfer Handoff Checkpoint

## Overview

This laboratory exercise focuses on Linux command-line basics, incident response workflows, and system inspection. The objective is to SSH into a target incident server, investigate an overnight transfer failure, locate the assigned case handoff details, and analyze the referenced logs to report the failed job ID and its total attempt count.

## Objectives

* **Login Directory:** Identify the complete directory path opened upon initial shell login.
* **Case ID:** Find the assigned case ID listed within the hidden home index file.
* **Case File:** Locate the full system path containing the assigned case handoff file.
* **Transfer Log:** Extract the full log path specified within the case handoff file.
* **Failed Job:** Identify the specific job ID that failed during the transfer operation.
* **Attempt Count:** Determine the total number of recorded transfer attempts for the failed job.
