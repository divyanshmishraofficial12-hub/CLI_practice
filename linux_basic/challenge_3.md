Practice 3: Dispatch Archive Search

Overview

This challenge focuses on Linux command-line basics, remote SSH connectivity, file search techniques, and archive inspection. The goal is to connect to a remote dispatch archive server, identify account group permissions, locate a missing handoff file, and analyze its content to answer specific objectives.

Objectives

Access Group: Identify the supplemental group assigned to the fieldtech user account that provides access to dispatch materials.

Handoff Path: Determine the complete system file path for HANDOFF.txt within the archive directory.

Job Code: Retrieve the job code displayed on the first line of HANDOFF.txt.

Destination: Identify the destination listed on the final line of HANDOFF.txt.
